## [Book Compare helper] - 2026-11-06
- New: the Book Compare helper (launcher/serve.ps1) reads the scan folders for Book Compare. Folders are chosen once in the Windows folder window and remembered as addresses in the project file: after restarting the computer there is no permission question at all, and the workspace works in Firefox too. Book Compare switches to this mode by itself when it is opened through the helper (http://localhost:8765/); opening index.html directly works as before
- The helper runs hidden: "Start Book Compare.bat" has no black window any more. An icon near the clock offers Open / Start with Windows / Quit. The first start asks (once) whether to start with Windows and whether to put a shortcut on the Desktop. A new download takes over from an older helper by itself; shortcuts follow when the folder is moved. "Start Book Compare (with window, for problems).bat" and "Stop Book Compare.bat" added
- Safety: the helper only answers Book Compare in a browser on the same computer (other web sites, other host names and requests without the Book Compare header are refused), only reads pictures inside folders you chose, never writes in scan folders, and writes nothing but book-compare-project.json in the project folder
- The project folder may now lie next to the copy folders (or in a folder that holds them). Only a folder that holds scans of the project is refused as a project folder (before: the whole scan folder tree)
- More menu: "Quit the Book Compare helper"
- Folder names with letters like a-umlaut work with the Windows PowerShell that comes with Windows 10/11 (found by the Windows test)
- tests: test_helper.py (real folders, Chromium and Firefox), tests/windows/windows-checks.ps1 and .github/workflows/windows-test.yml (GitHub tests the helper on a real Windows machine)

## [Book Compare launcher] - 2026-11-06
- New: "Start Book Compare.bat" starts Book Compare on your own computer with one double-click (a small local server, address http://localhost:8765/, only reachable from your own computer, no internet needed) and opens it in Edge. In Edge "Install this site as an app" is then possible (not possible when index.html is opened as a file), and the installed app also starts without the launcher. See START-HERE.txt
- START-HERE.txt: install path in Edge is "..." > More tools > Apps > Install Book Compare; the installed app keeps the folder permissions across restarts (tested by the author in Edge)
- Name in the browser tab, install dialog and Start menu is now "Book Compare" (was "Image Compare")
- tests/workspace: both automatic tests also pass when the app is served by the launcher script

## [Book Compare workspace v2.1] - 2026-11-06
- The folder window now opens where you chose a folder last time (the last scan folder, or the folder that holds the copies; separately for the project folder). Edge often forgets this when the app is opened from a file
- Less asking for permission after a restart: previews of pages you have looked at before are shown right away from the browser's memory; the browser's permission question now comes only when you press COMPARE (or when you click "Allow access now" to see every page). The question can not be removed completely: it is a browser rule

## [Book Compare workspace v2] - 2026-11-06
- Reopening a saved project no longer asks for the folder of every copy: scan folders are remembered as "folders used so far" (a folder that holds several copies is chosen once, later copies are picked from a list). After reopening, one click on "Allow access to scans" is enough per remembered folder; "Choose scan folder" / "Choose one folder for all" merges many copies into one folder. Projects saved by v1 still open and are converted
- "Set aside" row removed: "Delete file" removes a file from the workspace (the scan stays untouched; Undo and Delete key work)
- New "Add files to this copy ...": add deleted files again or pictures from another folder, at the end or from a chosen row (empty cells are filled first, otherwise the pages below move down)
- "Start numbering at this row" opens a window to choose pagination (Page 1, 2, 3 ...) or foliation (1r, 1v, 2r ...); More has "Switch to foliation / pagination"; rows you named yourself are kept when switching
- Add a copy: the name field stays empty and now shows the example "Austria, Austrian National Library"
- Two-image screen: "Perspective" is now the default transform mode
- tests/workspace: new test_roots.py (library folders, permission after reopening, projects from v1)

## [Book Compare workspace v1] - 2026-11-05
- New start-screen button "Compare copies of a book" opens the whole-book workspace (js/workspace.js, js/workspace.css)
- Add each copy as a folder of scans (Edge/Chrome folder picker; other browsers use a plain folder upload); pictures are placed in file-name order, no page numbers are read from file names; folders with several sub-folders can be combined
- Grid: columns = copies, rows = page positions, empty cells for missing pages; insert/close gaps, take files out and put them back, drag within a copy, rename copies and rows, "Start numbering at this row", "Don't compare this row", folio names, undo/redo
- Preview of the selected row for all copies (small thumbnails made in the browser, remembered between sessions); mark two pages with 1 and 2 and press COMPARE to open them in the two-image screen; Back there returns to the workspace
- Project is saved automatically as one small file in a separate project folder; Book Compare refuses a project folder that is, contains or lies inside a scan folder; scan folders are only read, never written
- Reopening a project: remembered scan folders are reused where the browser allows, otherwise "Choose scan folder" reconnects them in one step
- tests/workspace: automatic test with made-up scans (checks, among other things, that scan folders stay unchanged)
