BOOK COMPARE - START HERE
=========================

Book Compare compares scans of copies of early printed books, page by page.
It runs on your own computer. Your scans are never uploaded, and Book Compare only READS them:
it never changes, moves or deletes a scan. The only file it writes is the project file, in the
project folder you choose.


1. Install it (Windows 10 and 11)
---------------------------------
Download the newest installer from
    https://github.com/PeerPioneer/Book-Compare/releases/latest
(the file "Book-Compare-Setup-x.y.z.exe"; on the website, the link "Desktop program for
Windows" leads there) and run it.
 * Windows may say "Windows protected your PC" ("unknown publisher"), because the installer
   is not signed yet. Click "More info", then "Run anyway".
 * The installer asks for whom to install it (installed only for you, no administrator
   password is needed), where to install it, and whether Book Compare should appear in the
   Start menu and on the Desktop.


2. Every day
------------
Start Book Compare from the Start menu or the Desktop icon. It opens in its own window.
On the start screen choose "Compare copies of a book". Add each copy as a folder of scans
(the ordinary Windows folder window; or "Add single pictures ..." for a few files), then save
the project in a folder of its own ("More" > "Save project in a folder ..."). Book Compare
remembers your scan folders and your last project.


3. Updating
-----------
When a newer version is on the download page, Book Compare says so once a day ("Go to the
download page" / "Later"). Download the new installer and run it: it replaces the old
version; there is no need to remove the old one first. Your projects are not touched.


4. Removing it
--------------
Windows Settings > Apps > Installed apps > Book Compare > Uninstall. Your projects and scans
stay where they are.


If something does not work
--------------------------
 * A short log of what Book Compare did is kept in  %APPDATA%\Book Compare\book-compare.log
   (type that into the address bar of a File Explorer window).
 * Book Compare says it cannot read the scan folders: close it and open it again.
 * Still there from before November 2026: the old "helper" (a small icon near the clock and
   the files "Start Book Compare.bat"). It is no longer needed. Right-click its icon near the
   clock, untick "Start with Windows", choose "Quit Book Compare", and delete the old
   unzipped Book Compare folder. Projects made with it open in the program: "More" >
   "Open saved project ...", and choose the same project folder.


Without installing: the website
-------------------------------
https://peerpioneer.github.io/Book-Compare/ is the same Book Compare in the browser (Edge or
Chrome; Firefox with fewer comforts). Nothing is uploaded there either. The browser asks for
permission to your scan folders, which the desktop program does not need.
